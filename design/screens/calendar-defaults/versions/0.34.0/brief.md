# Persönlicher Kalenderstandard – Brief 0.34.0

Jedes Familienprofil soll den Kalender in der persönlich hilfreichen Ansicht öffnen. Tag, Woche oder Monat sowie eine optionale Kombination aus Personen- und Kalenderfiltern werden geräteübergreifend im bestehenden Profil gespeichert.

## Ziel

- bevorzugte Tag-, Wochen- oder Monatsansicht je Profil
- aktuelle Personen- und Kalenderfilter bewusst als Standard speichern
- Standard später überschreiben oder vollständig zurücksetzen
- keine stillen Schreibzugriffe bei jeder temporären Filteränderung
