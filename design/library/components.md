# Components

Prefer MUI defaults, variants, and central overrides. Add FamilyHub components only for repeated product behavior.

Atomic Design boundaries:

- Atoms: small branded controls and identity elements.
- Molecules: repeated rows, chips, banners, and empty states.
- Organisms: timelines, boards, lists, navigation, and setup flows.
- Templates: responsive page structure without feature data.

A screen specification must identify reused components before proposing new ones.
