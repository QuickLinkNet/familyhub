# Accessibility

- Target WCAG 2.2 AA contrast.
- Keep interactive touch targets at least 48 px where practical.
- Preserve visible keyboard focus and logical focus order.
- Never use color as the only status or person indicator.
- Respect `prefers-reduced-motion`.
- Specify loading, empty, error, disabled, and long-content states.
- Test desktop and mobile layouts in the built-in browser.
