# Rezeptverwaltung – Brief 0.31.0

Der vorhandene Essensplan wird um eine vollständige, alltagstaugliche Rezeptpflege ergänzt. Lieblingsgerichte sollen nicht nur gespeichert, sondern dauerhaft bearbeitet und für unterschiedliche Personenzahlen verwendet werden können.

## Ziel

- Rezepte mit Portionen, Kategorie, Zutaten und geordneten Zubereitungsschritten pflegen
- vorhandene Rezepte ohne Neuanlage bearbeiten
- Zutaten beim Übertragen auf eine Einkaufsliste an die gewünschte Portionszahl anpassen
- bestehende freie Mengenangaben und vorhandene Rezepte kompatibel weiterverwenden

## Freigabe

Der Funktionsumfang wurde vom Projektinhaber mit dem Start von Release 0.31 ausdrücklich freigegeben. Das Artefakt verwendet ausschließlich öffentliche Designgrundlagen und fiktive Beispiele.
