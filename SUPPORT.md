# Support

## Fragen und Fehler

- Reproduzierbare Fehler gehören in ein GitHub-Issue mit FamilyHub-Version, Umgebung und klaren Schritten.
- Funktionswünsche sollten das zugrunde liegende Problem im Familienalltag beschreiben.
- Installationsfragen benötigen mindestens PHP-Version, Webserver, Zielpfad und den bereinigten Fehlertext.

Bitte niemals Passwörter, OAuth-Secrets, private iCal-Adressen, Scheduler-URLs, Datenbanken, Archive oder echte Familiendaten veröffentlichen.

## Sicherheitsprobleme

Sicherheitslücken werden ausschließlich vertraulich über einen [privaten GitHub Security Advisory](https://github.com/QuickLinkNet/familyhub/security/advisories/new) gemeldet. Weitere Hinweise stehen in [SECURITY.md](SECURITY.md).

## Umfang

FamilyHub ist ein eigenständig betriebenes Projekt. Öffentliche Issues und Pull Requests werden nach verfügbarer Zeit bearbeitet; ein Anspruch auf individuelle Betriebs- oder Hostingunterstützung besteht nicht.
