# FamilyHub design rules

- Treat `src/theme/` as the source of truth for reusable design values.
- Separate preset, color scheme, and presentation mode.
- Preserve all approved behavior and data flows.
- Prefer MUI variants and existing Atomic Design components over new wrappers.
- Specify desktop, mobile, empty, loading, error, and long-content states.
- Target WCAG 2.2 AA, visible focus, keyboard access, and 48 px touch targets.
- Use anonymized example content and fictional people only.
- Keep working drafts private; commit only sanitized review artifacts.
- Do not request implementation before the screen version is `approved`.
