# Individuelle Termin-Erinnerungen – Brief 0.36.0

Lokale FamilyHub-Termine sollen mehrere bewusst gewählte Erinnerungszeitpunkte erhalten. Optional darf der Wandmodus bei einer fälligen Terminerinnerung einen kurzen, ruhigen Signalton ausgeben.

## Ziel

- keine, eine oder mehrere Erinnerungen pro lokalem Termin
- verständliche Vorlaufzeiten vom Startzeitpunkt bis einen Tag vorher
- optionaler ruhiger Signalton im Wandmodus
- vorhandene lokale Termine behalten den bisherigen Standard von zwei Stunden
- Google-Erinnerungen werden weiterhin ausschließlich bei Google verwaltet

## Freigabe

Der Funktionsumfang wurde vom Projektinhaber mit dem Start von Release 0.36.0 ausdrücklich freigegeben. Die Browser-Abnahme speichert keine echten Termine oder Erinnerungseinstellungen.
